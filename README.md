# Air Quality Index (AQI) Analysis — Indian Cities

## Project Overview
This project analyses Air Quality Index (AQI) data for Indian cities using Microsoft Power BI. The dashboard is designed to help users explore air quality patterns, compare cities and understand pollution levels.

## Project Objectives
- Analyse AQI levels across Indian cities.
- Compare air quality between locations.
- Identify pollution patterns and variations.
- Present insights through interactive visualisations.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query, if used for data cleaning
- DAX, if used for calculated measures
- Data visualisation and dashboard design

## Dashboard Pages
1. **AQI Overview:** Summary metrics and air quality comparisons.
2. **City-Level Analysis:** Detailed comparisons and trends, based on the visuals included in the report.

## Project Files
- `AQI_Dashboard.pbix` — Power BI report file.
- `AQI_Dashboard_Report.pdf` — PDF export of the report.
- `AQI_Dashboard_Page1.png` — Screenshot of Page 1.
- `AQI_Dashboard_Page2.png` — Screenshot of Page 2.

## How to Use
1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the available filters and visuals.

## Conclusion
This project demonstrates how Power BI can be used to explore air quality data and present location-based insights through interactive dashboards.
